# Welcome to your Kingdump

像素风如厕记录应用。记录时间与地点，在“屎迹”查看足迹，并用照片与装扮保存自己的如厕场景。

## 当前体验

[打开网页版](https://kingdump-lola.mightytoad6.chatgpt.site/)

当前记录和照片保存在使用者的浏览器本机，尚无云同步。更换浏览器或清除网站数据可能导致本机记录无法继续使用。

## 安装包

Android 和 iPhone 安装版本正在准备，目前没有正式安装包发布。

- Android：正式签名 APK 准备好后，将在本仓库的 Releases 提供。
- iPhone：测试或正式版本开放后，将在此提供安装入口。

本仓库用于分享官方安装版本、使用说明、更新日志和收集问题，不存放应用开发源码。

## 反馈

可以通过本仓库 Issues 反馈问题。请勿在公开反馈中上传密码、精确住址、私人照片或个人如厕记录。
